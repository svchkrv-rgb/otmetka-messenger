# Отметка

Корпоративный мессенджер проектной организации: группы по объектам, личные чаты, фото и видео, время прочтения сообщений, аудио- и видеозвонки.

Состоит из двух частей:

- **сервер** (`server/`) — Node.js, хранит всё у вас: база SQLite и файлы в одной папке `data`;
- **клиент** (`client/`) — React; работает в браузере и как приложение для Windows (Tauri).

## Что умеет первая версия

- Вход по логину и паролю. Сотрудников заводит администратор, самостоятельной регистрации нет.
- **Группы объектов**:
  - название, цвет, адрес;
  - роли «владелец», «администратор», «участник»;
  - добавление и исключение людей.
- Личные чаты.
- Текст, фото, видео и файлы до 500 МБ: кнопкой «+», перетаскиванием в окно или вставкой из буфера.
- **Время прочтения**:
  - в личном чате под сообщением видно «Прочитано в 10:05»;
  - в группе — «Прочитали 9 из 14» и список: кто во сколько прочитал, кто ещё нет;
  - прочтение засчитывается, только когда сообщение действительно на экране и окно приложения активно;
  - в настройках группы можно оставить прочтения видимыми только автору.
- Пометка «Важное» у сообщения.
- «Печатает…», статус «в сети» или «был(а) в 13:05», счётчики непрочитанных, уведомления Windows.
- **Звонки один на один**, аудио и видео:
  - входящий вызов с выбором «Ответить» или «Ответить с видео»;
  - выключение микрофона и камеры;
  - итог звонка записывается в чат («Исходящий видеозвонок · 3:12», «Пропущенный аудиозвонок»).

## 1. Запуск сервера

Нужен любой компьютер или сервер с Docker: офисный ПК, сервер или облако.

```bash
git clone https://github.com/svchkrv-rgb/otmetka-messenger.git
cd otmetka-messenger
docker compose up -d --build
```

Сервер работает на портах:

- **8080** (HTTP) — для приложения Windows;
- **8443** (HTTPS) — для браузера.

Проверка: откройте `http://АДРЕС-СЕРВЕРА:8080` — появится окно входа.

**Первый вход:** логин `admin`, пароль `admin`. Сразу смените пароль: Профиль → Сменить пароль.

> Без Docker: установите Node.js 22, затем
> `cd client && npm install && npm run build`, после этого `cd ../server && npm install && npm start`.

### Добавить сотрудников

Войдите администратором, откройте внизу **«Сотрудники»** и нажмите кнопку с человечком и плюсом. Укажите логин, имя, должность и пароль, затем передайте логин и пароль сотруднику. Через «⋯» у сотрудника можно сменить ему пароль или закрыть доступ.

## 2. Приложение для Windows

Установщик собирается автоматически при каждом изменении кода:

1. Откройте в репозитории вкладку **Actions** и выберите последнюю успешную (зелёную) сборку «Сборка и проверка».
2. Внизу в разделе **Artifacts** скачайте `otmetka-windows-setup`. Это zip, внутри файл `Otmetka_0.1.0_x64-setup.exe`.
3. Запустите установщик. Права администратора не нужны: приложение ставится для текущего пользователя.
4. При первом входе укажите **адрес сервера**, например `192.168.1.10:8080`, затем логин и пароль.

Windows SmartScreen может предупредить о неизвестном издателе, потому что установщик не подписан. Нажмите «Подробнее» → «Выполнить в любом случае». Для постоянной работы установщик стоит подписать сертификатом организации.

Чтобы выпустить версию с постоянной ссылкой, создайте тег `v0.1.0`: установщик появится во вкладке **Releases**.

## 3. Работа в браузере

Откройте `https://АДРЕС-СЕРВЕРА:8443`. Браузер предупредит о самоподписанном сертификате: «Дополнительно» → «Перейти на сайт».

HTTPS нужен потому, что браузеры дают доступ к камере и микрофону только по защищённому соединению. По адресу `http://…:8080` переписка работает, а звонки — нет. Приложение для Windows звонит и по HTTP.

## Звонки и сеть

- Внутри одной офисной сети звонки работают сразу.
- Через интернет (например, сотрудник на объекте с мобильным интернетом) соединение иногда не устанавливается из-за NAT. Тогда нужен TURN-сервер. Проще всего поднять **coturn** на той же машине и прописать его в `docker-compose.yml`, в переменной `ICE_SERVERS`. Пример там есть в комментарии.

## Резервное копирование

Всё хранится в папке `./data`: база `otmetka.db`, файлы в `uploads/`, ключи и сертификат. Достаточно регулярно копировать эту папку.

## Настройки сервера (переменные окружения)

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | 8080 | HTTP-порт |
| `HTTPS_PORT` | 8443 | HTTPS-порт с самоподписанным сертификатом; `0` — отключить |
| `DATA_DIR` | `./data` | Папка с базой и файлами |
| `ADMIN_LOGIN` / `ADMIN_PASSWORD` | admin / admin | Первый администратор (только при пустой базе) |
| `MAX_UPLOAD_MB` | 500 | Максимальный размер одного файла |
| `ICE_SERVERS` | публичный STUN Google | Серверы STUN/TURN для звонков, JSON |
| `JWT_SECRET` | создаётся сам | Ключ подписи сессий |

## Разработка

```bash
# сервер
cd server && npm install && npm run dev        # http://localhost:8080
# клиент в браузере с горячей перезагрузкой
cd client && npm install && npm run dev        # http://localhost:5173
# приложение Windows в режиме разработки (нужны Rust и WebView2)
cd client && npx tauri dev
# автотест сервера (сервер должен быть запущен с пустой базой)
node server/test/e2e.mjs
```

## Чего пока нет

Групповые звонки, редактирование и удаление сообщений, ответы и цитаты, поиск по истории, голосовые сообщения, мобильные приложения, подтверждение «важных» сообщений кнопкой. Всё это есть в макете и добавляется следующими шагами.
